# Crown of Static

Мрачная браузерная action-roguelite с видом сверху: магия, древние машины и мистическая цивилизация. Версия `0.4.0` добавляет редкости, тайные комнаты, контракты и классовые способы выполнять задания.

## Запуск

```bash
npm run serve
```

Откройте `http://localhost:4173`. Сборка и внешние зависимости не нужны.

## Управление

| Действие | Клавиша |
| --- | --- |
| Движение | `WASD` или стрелки |
| Рывок | `Space` |
| Классовая способность | `Q` |
| Пауза | `Esc` |
| Выбор улучшения | `1`, `2`, `3` или мышь |

На сенсорных устройствах автоматически появляются джойстик и кнопки способностей.

## Campaign 0.4.0

- защита Искры получила щит, восстановление за передышку и за активные убийства; стрелки охотятся на героя, а прорывающиеся к цели враги заранее отмечены в мире и на мини-карте;
- 45 улучшений пяти редкостей: обычные, редкие, эпические, легендарные и секретные; цвет редкости виден в выборе, сборке и Книге;
- в каждом секторе спрятана тайная комната со стражами и наградами, которые не появляются при обычном повышении уровня;
- перед забегом можно добровольно взять один из двух контрактов и получить дополнительное Эхо за выполнение условия;
- классы по-разному взаимодействуют с заданиями: Мечник защищает цель, Лучник видит тайники, Маг ускоряет активацию, Механист ремонтирует устройства;
- победа теперь завершается отдельной короткой сценой перед экраном результатов;
- 12 уровней по 3–6 минут, ветвящаяся карта и шесть типов заданий для второй главы;
- Мечник, Лучник, Маг и Механист, у каждого по две специализации с отдельными талантами, эффектами и цветом;
- Magnet притягивает весь оставленный на карте опыт и Scrap, а Scrap лечит процент от максимального здоровья;
- мини-карта показывает игрока, Magnet, Scrap, элиту, боссов и цели, но намеренно не обрабатывает осколки опыта;
- оружие визуально меняется с уровнем: растут модели, появляются руны, энергетические дуги, орбиты и детали дронов;
- события между секторами: Алтарь, Кузница, Аномалия, Архив, мастер и Неизвестный сигнал;
- фракции с поддержкой: щитоносцы защищают союзников, ремонтники лечат машины, дирижёры ускоряют отряды, Архивариусы блокируют способности;
- боссы проходят три фазы, заранее показывают опасные атаки и используют собственные правила арены;
- 9 постоянных улучшений Архива, расширенный набор реликвий, талантов и 10 слияний;
- Книга хранит проценты вкладок, подсказки, статистику, историю боссов, специализации, лучшие времена и последние сборки; рецепт можно закрепить в HUD;
- хард-режим меняет скорость и атаки противников, лечение, требования слияний, опасные зоны, элитные свойства и скрытый финал;
- бесконечный режим открывается после завершения всех 12 секторов.

## Проверка

```bash
npm test
```

Тесты проверяют математику игрового цикла, структуру кампании, рецепты слияний, DOM-контракты и наличие ресурсов.

## Технологии и планы

Игра написана на нативных HTML, CSS и JavaScript. Игровые данные отделены от логики и рендера, поэтому баланс кампании можно менять без сборщика. Следующая крупная цель — дополнительные главы, балансировка по статистике забегов и упаковка браузерной версии для Windows.
